# Orcub — component concept brief

Game: 2D mobile puzzle, portrait, dark background. Player rotates open "gear-rings"
(C-shaped rings with gear teeth on the outside and a ~60 degree GAP) so the gap lines up
with a HOLDER (a clamp that wraps around the ring's tube, attached by a short stem to a
neighbouring ring). When the gap passes the clamp, the clamp slips off and the rings separate.

We need ORIGINAL component art — explicitly NOT glossy neon candy-plastic tubes with
square translucent clips (that is a competitor's look we must not copy).

Components to show on each concept sheet (top-down orthographic view, as seen in game):
1. Gear-ring: open ring, teeth on the outer edge, clearly visible gap with nicely finished ends.
2. Holder: clamp that wraps the ring tube + short stem + weld/mount end that attaches to another ring.
3. The two together: a holder clamped on one gear-ring, stem welded to a second gear-ring.

Constraints:
- Must read clearly at small phone size on a dark navy/charcoal background.
- Simple, chunky forms that can be modeled in Blender from primitives (torus/extrudes/bevels).
- Base material should work in a NEUTRAL light tone so the game can tint each ring a different colour.
- Strong silhouette for the gap and for the clamp.
