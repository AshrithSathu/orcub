# Orcub — game UI prototype brief

Orcub is a portrait mobile puzzle game. Look at the references in this folder:
- ref_board.png: the game board — soft matte CLAY gear-rings in pastel colours, tan clay holders with rivets,
  on a warm dark PLUM FELT background. Everything looks hand-made, tactile, toy-like, softly lit from top-left.
- ref_icon.png: app icon (coral clay gear "o" with a tan clamp, on plum felt).
- ref_logo_options.png: logo is "orcub" in chunky rounded clay letters (Fredoka-like font), "o" = gear-ring.
- ref_current_hud.png / ref_current_win.png: our CURRENT UI — flat, generic, cheap-looking. Replace it.

The UI must feel like it was made of the SAME materials as the game: clay, felt, the tan "hardware" with
rivets, gear motifs. Chunky, soft, readable at phone size, premium casual-game quality (think top-grossing
casual puzzle polish) but ORIGINAL — not copying any existing game's UI.

Screens to show in each prototype sheet (three iPhone-portrait screens side by side, 9:16 each):
1. In-game HUD over the board: level number, moves-left counter, a pause/settings button, a restart button.
2. Level complete card: "Level 12" + 3 stars (earned/unearned states), coins earned, Next button,
   a small Replay button.
3. Out of moves card: "+5 moves" via watch-ad button, alternative "+5 moves for 9 cogs" (premium currency =
   brass cog coins), and a Give up / Retry option.
Use the Fredoka-style rounded font for all text. Spell everything correctly.
