# Orcub navigation prototypes v3

Image prototypes only. No Unity implementation or commits. Output scope: this directory only.

## Shared prompt / art direction
Create an ORIGINAL premium portrait iPhone puzzle game UI for Orcub. Soft matte sculpted CLAY, rounded puffy forms, gentle soft shadows, no gloss, no outlines. Deep plum FELT background; warm cream clay slabs, dark plum ink, chunky rounded friendly Fredoka-like typography. Mint primary, coral secondary, clay coral heart for lives, brass clay cog for currency. Pastel open gear-rings with tan clamps, as in the actual sprite references. Restrained palette and generous negative space, no decorative confetti. One obvious action. All labels readable and spelled exactly. Each individual screen is a full-bleed 9:19.5 portrait image, ideally 1179x2556 or nearest supported size with identical ratio. No perspective, no physical phone bezel. Reserve top 150px and bottom 100px as safe areas at 1179x2556, subtly show a notch/dynamic island and home indicator within those bands. Touch targets at least 132px (44pt at 3x). Controls must not overlap each other or artwork. Do not inherit layout from landscape ref_current_home.png: it is only a material reference and an example of poor hierarchy.

Home/Chapters/Map share identical cream resource HUD: coral heart '5', quiet 'Full', brass cog '120', small plus. Subscreens always have back button TOP LEFT below the safe area, aligned consistently with the HUD. Home uses Settings gear at top left in that slot. No lives spend on opening a level card. Saga has 200 levels, 10 chapters of 20, 3 stars per level, 600 total stars possible. Show chapter 1 progress 28/60 for 11 beaten levels; level 12 is frontier, levels 13 onward locked. Workshop restoration spends earned stars separately: current task 'Fix the lamp' with '2/3 stars'. Lamp, clock, toolbox and music box are compact meta objects, never a giant foreground scene.

Use Codex CLI native image generation as earlier rounds did. Run from project root; read this brief and view refs; use image generation tool for artwork, save generated PNGs from ~/.codex/generated_images to exact names above. Generate each screen separately, never a multi-variant sheet for individual screen outputs. Inspect output and fix substantive generation defects before finalising. Do not use handdrawn code/SVG as a replacement for image generation. You may use Pillow only for lossless crop/padding/resizing/compositing overview thumbnails, not for inventing UI artwork. Keep only final named images, ref files, this BRIEF.md, ranking.md and gen.log in output directory. Do not delete pre-existing refs. No edits outside output directory; no commits. Do not start agents or delegate. Log actual prompts and outputs in gen.log. The caller will perform final ranking after viewing all images.
