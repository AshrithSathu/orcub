# Orcub v3 — design ranking

These are image concepts for approval, not implemented interfaces. Preferred set: **Home C → Chapters A → Map A → Level-start B**.

| Screen | Rank | Pick and reason |
|---|---|---|
| Home | C > A > B | **C:** one coherent chapter ticket leads to Play, the lamp task is compact, and All levels stays separate. No permanent tab dock to compete with the main action. **A:** strong Play hierarchy but the decorative gear cluster consumes more space. **B:** easiest persistent navigation to reach with a thumb, but duplicates Levels / All levels and gives the workshop shelf more visual weight. |
| Chapters | A > B | **A:** full-width cards make ranges, progress and lock conditions easy to scan; large hit regions support one-handed use. **B:** useful gallery overview, but narrower cards and more visible locks add density. |
| Map | A > B | **A:** the open felt trail is quieter and makes the mint frontier stand out; numbered nodes and earned stars remain easy to distinguish. **B:** tangible workshop tray has character, but the cream surface and object recesses add weight around the route. |
| Level start | B > A | **B:** Play sits in the lower thumb zone, the selected node remains visible, and the sheet establishes a clear foreground. **A:** smaller, lighter interruption and a good alternative if preserving more map is the priority; its Play target sits higher. |
| Booster feedback | Keep | Hint identifies a specific ring and turn direction; Undo visibly reverses a turn and separately shows disabled empty history; Unclamp shows the detached clamp, attachment point and puff. Board motion must carry the feedback, not just the toast. |
| Flow | Keep as navigation reference | The board illustrates Home A as an alternative, then Chapters A / Map A / Level start B, with the direct Home Play shortcut, Win/Lose returns and Retry. Home C can replace Home A without changing the navigation. |

## Approval notes

- Score thresholds 100 / 200 / 300 and the 1-life start label are illustrative prototype copy, not approved game rules.
- Portrait exports are 1179×2556 (9:19.5). Generated art was fitted uniformly on felt and composed with a shared HUD; clay shapes were not stretched. Top island and bottom indicator areas are reserved.
- The HUD consistently orders lives before currency; all sub-screens use the same top-left back control. Home uses a settings cog in that position.
- Thumb reach and hit-area judgments are visual design judgments only. No Unity, device or interactive accessibility checks were performed.
- Existing landscape screenshots were used only as material references. No Assets, Scripts or Unity settings were edited and no commit was created.
